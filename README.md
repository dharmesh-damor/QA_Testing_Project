# E-Commerce Website QA Testing Project

A practical Software QA portfolio project demonstrating manual testing and QA documentation for a sample e-commerce web application.

## Scope
- Registration and login
- Product search and filtering
- Product details
- Shopping cart
- Checkout and order placement
- Form validation and usability

## QA Activities
- Requirement analysis
- Test scenario and test case design
- Functional and negative testing
- Regression testing
- Defect reporting
- Test summary reporting


> Portfolio note: test results and defects are sample data created to demonstrate QA documentation skills; they are not claims about a specific production website.
