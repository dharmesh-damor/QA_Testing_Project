# Test Plan

## Objective
Validate the core functionality, usability, and reliability of a sample e-commerce application before release.

## In Scope
- Registration/login
- Product search, filters, and product details
- Cart quantity, add/remove, and totals
- Checkout and order placement
- Form validation
- Basic responsive/usability checks

## Out of Scope
- Payment gateway certification
- Production performance benchmarking
- Security penetration testing
- Third-party service certification

## Test Types
- Functional testing
- Negative testing
- Smoke testing
- Regression testing
- UI/usability testing
- Compatibility checks

## Entry Criteria
- Build deployed to test environment
- Testable requirements available
- Core services available

## Exit Criteria
- Critical/high defects resolved or formally accepted
- Planned cases executed
- Regression completed for impacted areas
- Test summary prepared

## Deliverables
- Test cases
- Defect reports
- Regression checklist
- Test summary report
